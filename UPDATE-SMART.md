# Atualizações do VectorSmart

A interface inclui **Ajuda > Verificar atualizações**, que abre a página da versão mais recente:

https://github.com/DisneyMjr/DISNEY-VECTOR-STUDIO/releases/latest

## Publicar uma atualização

1. Envie alterações para `main`.
2. Abra GitHub Actions > **Publicar versão VectorSmart**.
3. Digite a versão (exemplo: `0.3.0`) e execute.
4. Após a compilação, confira **Releases** e o arquivo MSI publicado.

**Limitação:** verificar atualizações abre a página Releases, não instala automaticamente. O usuário deve baixar e executar o MSI. Não há execução automática em segundo plano ou alteração silenciosa.

Os instaladores atuais não foram compilados nem testados nesta sessão. Antes de publicar para seus usuários, valide a compilação e teste a instalação/atualização numa máquina limpa.

Se o repositório estiver privado, somente usuários autorizados podem acessar Releases.
